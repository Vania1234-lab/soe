COMO ABRIR NO VS CODE

MÉTODO MAIS FÁCIL

1. Extraia o ZIP inteiro para uma pasta.
2. Não abra os arquivos ainda dentro do ZIP.
3. Entre na pasta extraída.
4. Dê dois cliques em ABRIR-SISTEMA.bat.
5. Uma janela preta ficará aberta.
6. O navegador abrirá em:
   http://localhost:5500/index.html

PAINEL DO PROFESSOR

http://localhost:5500/prof.html

IMPORTANTE

- Não feche a janela preta enquanto estiver usando o sistema.
- Não abra index.html com dois cliques.
- Não use file:///.
- No Firebase Authentication > Settings > Authorized domains,
  confirme que localhost está autorizado.

ABRINDO PELO LIVE SERVER

1. Abra a pasta inteira no VS Code.
2. Clique em Go Live.
3. Esta pasta já está configurada para localhost:5500.
4. Abra:
   http://localhost:5500/index.html

Se aparecer ERR_CONNECTION_REFUSED, o servidor não está rodando.
Se aparecer auth/unauthorized-domain, adicione localhost nos domínios autorizados do Firebase.
